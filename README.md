# WebDB-Project 🌐💻

**WebDB-Project** is a full-stack web application that demonstrates how **JavaScript and PHP** can be integrated with a **MySQL database** to create interactive and dynamic web pages. The project enables users to manage, display, and update data in real time through a web interface.

---

## 📌 Overview
This project combines **frontend and backend technologies** to build a functional and responsive web system.  
- **Frontend**: HTML, CSS, and JavaScript for dynamic content and user interaction  
- **Backend**: PHP scripts to handle database operations, form submissions, and server logic  
- **Database**: MySQL for storing, querying, and managing application data  

It is suitable for learning **full-stack web development**, database integration, and real-time data handling.

---

## ✨ Features
- Dynamic web pages with JavaScript interactivity  
- PHP-based server-side processing  
- MySQL database integration for storing and retrieving data  
- User-friendly forms and tables for data management  
- Basic authentication or session handling (optional)  
- Modular design for easy extension and maintenance  

---

## 🛠 Requirements
- **Software**:  
  - Web server (XAMPP, WAMP, or similar)  
  - PHP 7+  
  - MySQL 5+  
  - Web browser (Chrome, Firefox, etc.)  

- **Optional tools**:  
  - phpMyAdmin or MySQL Workbench for database management  
  - Git for version control  

---

## ⚙️ Setup
1. Clone the repository:  
   ```bash
   git clone https://github.com/YIJ18/WebDB-Project.git
   cd WebDB-Project
   ```
2. Import the database using the provided `.sql` file.  
3. Configure database connection in the PHP files (host, username, password, database name).  
4. Start the web server and open the project in a browser.  

---

## 🚀 Usage
- Navigate through the web interface to add, update, or delete data entries.  
- Forms interact with the database through PHP scripts.  
- Dynamic content updates in real time using JavaScript.
